IBM Plex Sans (Regular, Medium, SemiBold, Bold) and IBM Plex Mono (Regular,
Bold), from the [IBM Plex repository](https://github.com/IBM/plex/tree/master/packages).
Distributed under the accompanying [SIL Open Font License](OFL.txt).

The launcher installs these files in the user's font directory so live
Conky and the headless Cairo renderer use the same faces.

Lucide icon path data is vendored separately in `conky/lucide-icons.lua`, under
the ISC license in [`../LUCIDE-LICENSE.txt`](../LUCIDE-LICENSE.txt).
